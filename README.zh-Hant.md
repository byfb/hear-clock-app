# Hear Clock

輕點 Android 主畫面上的時鐘，就能聽到現在幾點。這個時鐘小工具可以調整大小，方便盲人和低視能人士使用。

[下載 Android 版（適用於 Android 8.0 或以上版本）](https://github.com/byfb/hear-clock/releases/latest) · [English](README.md) · [简体中文](README.zh-Hans.md)

開啟 Hear Clock，點選 **Add widget**（加入小工具）並確認。使用 TalkBack 時，先將焦點移到主畫面上的時鐘，再輕點兩下即可報時。
