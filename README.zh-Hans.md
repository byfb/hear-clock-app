# Hear Clock

点一下 Android 桌面上的时钟，就能听到现在几点。这款时钟小组件可以调整大小，方便盲人和低视力用户使用。

[下载 Android 版（适用于 Android 8.0 及以上版本）](https://github.com/byfb/hear-clock/releases/latest) · [English](README.md) · [繁體中文](README.zh-Hant.md)

打开 Hear Clock，点 **Add widget**（添加小组件）并确认。使用 TalkBack 时，先把焦点移到桌面上的时钟，再轻点两下即可报时。
